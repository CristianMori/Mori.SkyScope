# Mori.SkyScope

Real-time data visualization for robotics, automation and data-heavy applications: an IOComp-class trend chart, dashboard gauges,
analytic charts and a composable map/scene view. One headless core in C# (this package family) and TypeScript, kept
identical by shared fixtures; renderers for SkiaSharp (WPF), Blazor and React.

Packages: `Mori.SkyScope.Core` (engine), `Mori.SkyScope.Render.Skia`, `Mori.SkyScope.Wpf`, `Mori.SkyScope.Blazor`,
`Mori.SkyScope.Streaming`, `Mori.SkyScope.Sources.Mqtt`, `Mori.SkyScope.Sources.Ros2`.

Documentation and samples: https://github.com/CristianMori/Mori.SkyScope
